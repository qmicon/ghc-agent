# Shopify Offer Page Implementation Plan: "Buy 3 for 99"

## 1. Implementation Steps

### Step 1: Create the Template File
- Create `templates/page.offer.json` to define the page structure
- Include all required sections in the correct order

### Step 2: Create the Banner Section
- Create `sections/offer-banner.liquid` for the top promotional banner
- Implement settings for customizable heading, subtext, and background image

### Step 3: Create the Product Grid Section
- Create `sections/offer-product-grid.liquid` to display selectable products
- Implement product selection functionality with a limit of 3 products
- Create visual indicators for selected products

### Step 4: Create the Selected Products Section
- Create `sections/offer-selected-products.liquid` for the sticky bottom section
- Display selected products and implement the checkout button
- Ensure the checkout button is disabled until 3 products are selected

### Step 5: Create Supporting Snippets
- Create `snippets/offer-product-card.liquid` for consistent product display
- Create `snippets/offer-selected-item.liquid` for the selected product slots

## 2. Required Components

### Sections
1. **offer-banner**
   - Purpose: Display promotional heading and subtext with background image
   - Functionality: Fully customizable through section settings

2. **offer-product-grid**
   - Purpose: Display selectable products in a grid layout
   - Functionality: Allow product selection with a limit of 3 products
   - Interactions: Updates the selected products section when products are selected

3. **offer-selected-products**
   - Purpose: Display selected products and checkout button
   - Functionality: Show selected products, enable/disable checkout button
   - Interactions: Receives updates from the product grid section

### Snippets
1. **offer-product-card**
   - Purpose: Consistent display of products in the grid
   - Functionality: Display product image, name, and selection button
   - Used by: offer-product-grid section

2. **offer-selected-item**
   - Purpose: Display selected product in the bottom section
   - Functionality: Show product image and name in a slot
   - Used by: offer-selected-products section

## 3. File Structure

1. **templates/page.offer.json**
   - Purpose: Define page structure and section order
   - Dependencies: All sections defined in this file

2. **sections/offer-banner.liquid**
   - Purpose: Display promotional banner
   - Dependencies: None

3. **sections/offer-product-grid.liquid**
   - Purpose: Display and manage selectable products
   - Dependencies: offer-product-card snippet

4. **sections/offer-selected-products.liquid**
   - Purpose: Display selected products and checkout button
   - Dependencies: offer-selected-item snippet

5. **snippets/offer-product-card.liquid**
   - Purpose: Reusable product card component
   - Dependencies: None

6. **snippets/offer-selected-item.liquid**
   - Purpose: Reusable selected product component
   - Dependencies: None

## 4. Implementation Notes

### General Architecture
- We'll use a global state management approach using JavaScript to track selected products
- The state will be shared between the product grid and selected products sections
- We'll use custom events to communicate between sections
- All components will be responsive and mobile-friendly

### Error Handling Strategy
- Validate user selections to prevent selecting more than 3 products
- Provide clear visual feedback when the limit is reached
- Handle edge cases like unavailable products
- Ensure graceful degradation if JavaScript is disabled

<script>
  document.addEventListener('DOMContentLoaded', function() {
    // Initialize the offer product selection functionality
    const offerProductGrid = {
      maxSelections: 3,
      selectedProducts: [],
      
      init: function() {
        this.setupEventListeners();
        this.updateUI();
      },
      
      setupEventListeners: function() {
        const productCards = document.querySelectorAll('.offer-product-card');
        
        productCards.forEach(card => {
          const selectButton = card.querySelector('.offer-product-card__select');
          
          selectButton.addEventListener('click', (event) => {
            event.preventDefault();
            const productId = card.getAttribute('data-product-id');
            const productTitle = card.getAttribute('data-product-title');
            const productImage = card.getAttribute('data-product-image');
            
            this.toggleProductSelection({
              id: productId,
              title: productTitle,
              image: productImage
            }, card);
          });
        });
      },
      
      toggleProductSelection: function(product, card) {
        const isSelected = card.classList.contains('selected');
        
        if (isSelected) {
          // Remove product from selection
          this.selectedProducts = this.selectedProducts.filter(p => p.id !== product.id);
          card.classList.remove('selected');
          card.querySelector('.offer-product-card__select').textContent = 'Select';
        } else {
          // Add product to selection if under max limit
          if (this.selectedProducts.length < this.maxSelections) {
            this.selectedProducts.push(product);
            card.classList.add('selected');
            card.querySelector('.offer-product-card__select').textContent = 'Selected';
          } else {
            // Show message that max selections reached
            const messageEl = document.getElementById('selection-message');
            messageEl.textContent = 'Maximum 3 products already selected';
            messageEl.classList.add('error');
            
            setTimeout(() => {
              messageEl.textContent = 'Select up to 3 products for ₹99';
              messageEl.classList.remove('error');
            }, 3000);
          }
        }
        
        this.updateUI();
        this.notifySelectedProductsSection();
      },
      
      updateUI: function() {
        // Update counter
        document.getElementById('selected-count').textContent = this.selectedProducts.length;
        
        // Update product cards state
        const productCards = document.querySelectorAll('.offer-product-card');
        
        productCards.forEach(card => {
          const productId = card.getAttribute('data-product-id');
          const isSelected = this.selectedProducts.some(p => p.id === productId);
          const selectButton = card.querySelector('.offer-product-card__select');
          
          if (isSelected) {
            card.classList.add('selected');
            selectButton.textContent = 'Selected';
          } else {
            card.classList.remove('selected');
            selectButton.textContent = 'Select';
            
            // Disable non-selected cards if max selections reached
            if (this.selectedProducts.length >= this.maxSelections) {
              selectButton.disabled = true;
              card.classList.add('disabled');
            } else {
              selectButton.disabled = false;
              card.classList.remove('disabled');
            }
          }
        });
      },
      
      notifySelectedProductsSection: function() {
        // Create and dispatch custom event with selected products data
        const event = new CustomEvent('offerProductsSelected', {
          detail: {
            selectedProducts: this.selectedProducts
          }
        });
        
        document.dispatchEvent(event);
      }
    };
    
    offerProductGrid.init();
  });
</script>

<script>
  document.addEventListener('DOMContentLoaded', function() {
    // Initialize the selected products section
    const selectedProductsSection = {
      selectedProducts: [],
      maxSelections: 3,
      
      init: function() {
        this.setupEventListeners();
        this.updateUI();
      },
      
      setupEventListeners: function() {
        // Listen for product selection events from the product grid
        document.addEventListener('offerProductsSelected', (event) => {
          this.selectedProducts = event.detail.selectedProducts;
          this.updateUI();
        });
        
        // Setup checkout button
        const checkoutButton = document.getElementById('checkout-button');
        checkoutButton.addEventListener('click', this.handleCheckout.bind(this));
        
        // Setup remove buttons for selected items
        document.addEventListener('click', (event) => {
          if (event.target.classList.contains('offer-selected-item__remove')) {
            const productId = event.target.getAttribute('data-product-id');
            this.removeProduct(productId);
          }
        });
      },
      
      updateUI: function() {
        // Update product slots
        for (let i = 1; i <= this.maxSelections; i++) {
          const slotElement = document.getElementById(`product-slot-${i}`);
          
          // Clear existing content
          while (slotElement.firstChild) {
            slotElement.removeChild(slotElement.firstChild);
          }
          
          if (i <= this.selectedProducts.length) {
            // Populate slot with product
            const product = this.selectedProducts[i-1];
            slotElement.classList.remove('empty');
            
            const selectedItem = document.createElement('div');
            selectedItem.className = 'offer-selected-item';
            
            const image = document.createElement('img');
            image.className = 'offer-selected-item__image';
            image.src = product.image;
            image.alt = product.title;
            
            const removeButton = document.createElement('button');
            removeButton.className = 'offer-selected-item__remove';
            removeButton.setAttribute('data-product-id', product.id);
            removeButton.innerHTML = '×';
            
            selectedItem.appendChild(image);
            selectedItem.appendChild(removeButton);
            slotElement.appendChild(selectedItem);
          } else {
            // Show empty slot
            slotElement.classList.add('empty');
            const placeholder = document.createElement('div');
            placeholder.className = 'offer-selected-products__placeholder';
            placeholder.textContent = i;
            slotElement.appendChild(placeholder);
          }
        }
        
        // Update checkout button state
        const checkoutButton = document.getElementById('checkout-button');
        checkoutButton.disabled = this.selectedProducts.length !== this.maxSelections;
      },
      
      removeProduct: function(productId) {
        // Remove product from selection
        this.selectedProducts = this.selectedProducts.filter(p => p.id !== productId);
        
        // Update UI
        this.updateUI();
        
        // Notify product grid about the change
        this.notifyProductGrid();
      },
      
      notifyProductGrid: function() {
        // Create and dispatch custom event with updated selected products
        const event = new CustomEvent('offerProductsUpdated', {
          detail: {
            selectedProducts: this.selectedProducts
          }
        });
        
        document.dispatchEvent(event);
        
        // Also update product grid UI directly
        const productCards = document.querySelectorAll('.offer-product-card');
        
        productCards.forEach(card => {
          const productId = card.getAttribute('data-product-id');
          const isSelected = this.selectedProducts.some(p => p.id === productId);
          const selectButton = card.querySelector('.offer-product-card__select');
          
          if (isSelected) {
            card.classList.add('selected');
            selectButton.textContent = 'Selected';
          } else {
            card.classList.remove('selected');
            selectButton.textContent = 'Select';
            selectButton.disabled = false;
            card.classList.remove('disabled');
          }
        });
        
        // Update counter in product grid
        document.getElementById('selected-count').textContent = this.selectedProducts.length;
      },
      
      handleCheckout: function() {
        if (this.selectedProducts.length !== this.maxSelections) {
          return;
        }
        
        // Create array of variant IDs for cart
        const variantIds = this.selectedProducts.map(p => p.id);
        
        // Add items to cart with special properties to indicate they're part of the offer
        const formData = {
          items: variantIds.map(id => ({
            id: id,
            quantity: 1,
            properties: {
              '_offer': 'Buy 3 for 99',
              '_bundle_id': new Date().getTime()
            }
          }))
        };
        
        // Show loading state
        const checkoutButton = document.getElementById('checkout-button');
        const originalText = checkoutButton.textContent;
        checkoutButton.textContent = 'Adding to cart...';
        checkoutButton.disabled = true;
        
        // Add to cart via AJAX
        fetch('/cart/add.js', {
          method: 'POST',
          headers: {
            'Content-Type': 'application/json'
          },
          body: JSON.stringify(formData)
        })
        .then(response => {
          if (!response.ok) {
            throw new Error('Network response was not ok');
          }
          return response.json();
        })
        .then(data => {
          // Redirect to cart page
          window.location.href = '/cart';
        })
        .catch(error => {
          console.error('Error adding products to cart:', error);
          
          // Reset button state
          checkoutButton.textContent = originalText;
          checkoutButton.disabled = false;
          
          // Show error message
          alert('There was an error adding products to your cart. Please try again.');
        });
      }
    };
    
    selectedProductsSection.init();
    
    // Listen for product updates from the selected products section
    document.addEventListener('offerProductsUpdated', function(event) {
      // This event is used by the product grid to update its state
      const productGrid = document.getElementById('offer-product-grid');
      if (productGrid) {
